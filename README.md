# NexifyBot ✨

بات خصوصی برای آماده‌سازی دستی انتشار ریلز: کاربر مجاز ویدیو می‌فرستد، بات آن را با نمونه‌برداری از شش فریم و متن صدای استخراج‌شده تحلیل می‌کند، برای ایده‌های مرتبط در وب جست‌وجو می‌کند و یک فایل ZIP برای مدیر می‌فرستد. ZIP شامل ویدیوی اصلی، فریم انتخاب‌شده به عنوان کاور، کپشن و هشتگ، پیشنهاد بیو، متن کاور، تحلیل و منابع و متن صداست. متن کاور روی تصویر نوشته نمی‌شود. هیچ ویدیویی به اینستاگرام آپلود نمی‌شود.

## پیش‌نیازهای واقعی

* یک بات تلگرام و **توکن جدید و محرمانه** آن. در BotFather نام نمایشی را NexifyBot بگذارید؛ نام کاربری باید در تلگرام آزاد باشد. تصویر `nexify-profile.jpg` را با دستور `/setuserpic` در BotFather تنظیم کنید.
* یک کلید معتبر Gemini API با سهمیه در دسترس، یا یک حساب OpenAI API با اعتبار پرداخت. Gemini دارای سهمیه رایگان محدود است؛ دسترسی و محدودیت‌ها را در حساب خود بررسی کنید. Gemini اطلاعات ویدیو را به گوگل ارسال می‌کند و داده‌های سهمیه رایگان ممکن است برای بهبود خدمات گوگل استفاده شوند.
* شناسه عددی تلگرام مدیر و همکاران مجاز، نه نام کاربری. دستور `/id` در گفت‌وگوی خصوصی با بات شناسه عددی خود کاربر را نشان می‌دهد و دسترسی به بات نمی‌دهد. قبل از آنکه بات راه‌اندازی شود می‌توانید از یک بات شناسه‌یاب معتبر استفاده کنید. مدیر حتماً باید یک بار `/start` را برای بات بفرستد تا تلگرام اجازه ارسال فایل به او بدهد.
* مخزن GitHub و حساب Render برای اجرای آنلاین. GitHub به‌تنهایی میزبان دائمی بات نیست.

## راه‌اندازی روی Render

1. فایل‌های پروژه را در مخزن GitHub خود قرار دهید. فایل‌های حاوی رمز یا کلید را commit نکنید.
2. در Render یک Blueprint از مخزن بسازید تا `render.yaml` خوانده شود. از کاربر حساب Render خواسته می‌شود مقادیر محرمانه را در داشبورد وارد کند.
3. مقدارهای زیر را فقط در تنظیمات Environment سرویس وارد کنید:
   * `TELEGRAM_BOT_TOKEN`: توکن تازه‌ای که BotFather داده است.
   * `OPENAI_API_KEY`: کلید جدید OpenAI API با اعتبار و دسترسی لازم.
   * `GEMINI_API_KEY`: کلید Gemini. وقتی این متغیر تنظیم باشد، Gemini به جای OpenAI استفاده می‌شود. مقدار `GEMINI_MODEL` در صورت نیاز قابل تغییر است.
   * `TELEGRAM_OWNER_ID`: شناسه عددی مدیر، برای دریافت ZIP و گزارش خطا.
   * `TELEGRAM_ALLOWED_IDS`: شناسه‌های عددی مجاز، جداشده با کاما؛ مدیر به‌طور خودکار مجاز است. مثال `123456789,987654321`.
   * `WEBHOOK_SECRET` به‌طور تصادفی توسط Blueprint ساخته می‌شود؛ مقدار آن را محرمانه نگه دارید. `RENDER_EXTERNAL_URL` توسط Render به سرویس داده می‌شود.
4. سرویس را deploy کنید و لاگ را بررسی کنید. در صورت نیاز `OPENAI_MODEL` و `OPENAI_TRANSCRIPTION_MODEL` را مطابق دسترسی حساب تنظیم کنید؛ پیش‌فرض‌ها `gpt-6.2-astra` و `gpt-transcribe` هستند.
5. مدیر در چت خصوصی بات `/start` بزند. هر همکار برای دسترسی باید شناسه عددی‌اش در `TELEGRAM_ALLOWED_IDS` ثبت شود و سرویس با تنظیمات جدید مجدداً راه‌اندازی شود. سپس یک ویدیوی آزمایشی ارسال کنید و دریافت ZIP در چت مدیر را بررسی کنید.

## محدودیت‌ها و رفتار عملیاتی

* API معمولی تلگرام فایل ورودی را تا ۲۰ مگابایت قابل دانلود می‌کند؛ سقف مدت این برنامه ۱۵ دقیقه است. هم‌زمان یک ویدیو پردازش می‌شود و فایل‌های اضافی باید دوباره ارسال شوند.
* فایل ورودی و فریم‌ها موقت هستند و بعد از هر پردازش حذف می‌شوند. با این حال تصویر و صدای ویدیو برای تحلیل به سرویس OpenAI ارسال می‌شود؛ فقط ویدیوهایی را ارسال کنید که اجازه پردازششان را دارید.
* وب‌هوک پس از دریافت در صف حافظه قرار می‌گیرد. با خاموش‌شدن، restart یا deploy هنگام پردازش، کار ممکن است از دست برود؛ آن را مجدداً بفرستید. پردازش دائمی و تحویل تضمین‌شده به صف و فضای ذخیره‌سازی پایدار نیاز دارد.
* سرویس رایگان Render پس از بی‌کاری به خواب می‌رود، شروع مجدد می‌تواند تأخیر داشته باشد و ممکن است سرویس قطع یا محدود شود. این راهکار تضمین ۲۴ ساعته ندارد.
* بررسی محتوا فقط بر اساس شش فریم نمونه و صوت است و ممکن است جزئیات را از دست بدهد. در حالت Gemini تیترهای خبری مرتبط به صورت اختیاری جست‌وجو می‌شوند؛ این داده‌ها رتبه ترند اینستاگرام نیستند و در صورت دسترس نبودن با ذکر محدودیت ادامه می‌یابد. نتیجه را قبل از انتشار بازبینی کنید.
* در صورت خطا، ZIP موفق اعلام نمی‌شود. تنظیمات، دسترسی مدل، اعتبار API و لاگ سرویس را بررسی کنید. گزارش تلگرام زمانی ارسال می‌شود که مدیر قبلاً بات را شروع کرده باشد.

## آزمون

پس از نصب وابستگی‌ها: `python -m unittest discover -s tests -v`. این آزمون‌ها از سرویس واقعی استفاده نمی‌کنند و جایگزین آزمون عملی بعد از تنظیم کلیدها نیستند.
